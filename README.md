# 🐾 街头撸宠手账 · Street Pet Diary

> **今天出门，会摸到哪只小可爱？**

一个轻量、可爱的街头撸宠记录小工具。

出门在街上遇到小猫、小狗，摸一摸，拍张照片，记录一下当时的心情和地点，把这一次短暂的相遇保存成一张属于自己的 **「撸宠纪念卡」**。

不用记住它的名字，  
但可以记住那天摸到它的瞬间。 🐈🐕

---

## ✨ 这个小工具可以做什么？

### 📸 记录一次街头相遇

遇到喜欢的小猫小狗后，可以：

- 上传现场照片
- 给它取一个名字
- 选择动物类型
- 记录它当时的状态
- 记录相遇地点
- 写下一小段撸宠日记

然后，把这次相遇保存下来。

### 🎴 生成专属「撸宠纪念卡」

保存记录后，会生成一张专属的街头撸宠纪念卡。

每一位被你摸过的毛孩子，都拥有自己的编号：

`NO.001`  
`NO.002`  
`NO.003` …

像是在慢慢收集一本属于自己的 **Street Pet Diary**。

### 🐾 收进「我的撸宠手账」

所有记录都会进入自己的街头撸宠手账，可以随时查看过去遇见的小家伙。

首页也会展示最近记录，让每一次打开工具，都能重新想起最近摸过的毛孩子。

### 🎨 一点小小的仪式感

保存记录时，会出现一个类似「收进纪念球」的动画效果。

不是为了真的把动物“收集起来”，而是给一次普通的街头相遇增加一点游戏般的小仪式感。

---

## 🔒 隐私 & 数据

这个项目**不需要服务器，也不需要账号登录**。

照片和记录直接保存在当前浏览器的 **IndexedDB** 中。

也就是说：

- ❌ 不上传照片到服务器
- ❌ 不需要注册账号
- ❌ 不需要数据库
- ❌ 不需要第三方 API
- ❌ 不需要 AI API
- ✅ 数据保存在当前设备的浏览器中

因此，这个项目也非常适合作为一个简单的个人 H5 / GitHub Pages 小工具。

项目使用 IndexedDB 保存记录，新增、读取和删除记录都直接在浏览器本地完成。

## 🛠️ 技术栈

这是一个非常轻量的纯前端项目。

- HTML
- CSS
- JavaScript
- IndexedDB
- Canvas API

没有使用前端框架，也没有后端服务。

核心记录结构直接存储在浏览器 IndexedDB 中；上传的照片会读取为 Data URL 后保存到本地记录。 

纪念卡的下载也由浏览器端 Canvas 直接生成 PNG，不依赖第三方图片服务。

## 💡 为什么做这个？

很多时候，我们在街上遇到一只猫、一只狗。

可能只相处了几分钟。

摸摸它的头，看它蹭蹭你的手，拍一张照片，然后各自继续走自己的路。

它可能根本不知道你的名字，  
你也未必知道它叫什么。

但那几分钟，确实让普通的一天变得有一点不一样。

所以想做一个很简单的小工具：

> **记录那些短暂、随机、但让人觉得很开心的街头相遇。**

不需要认真经营。

也不需要完成什么任务。

只是偶尔打开看看：

**「啊，我以前摸过这只小猫。」**
